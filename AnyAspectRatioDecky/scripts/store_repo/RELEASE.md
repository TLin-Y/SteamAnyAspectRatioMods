# AnyAspectRatio 2.1.0 (Decky Plugin Store build)

Same plugin as [SteamAnyAspectRatioMods 2.1.0](https://github.com/TLin-Y/SteamAnyAspectRatioMods), built for the Decky Plugin Store.

- Self-updater removed: updates come from the Decky Plugin Store.
- No offline pack here. Get it from the [mod repository releases](https://github.com/TLin-Y/SteamAnyAspectRatioMods/releases/latest) if needed.

## Manual install

Decky **Settings → Developer → Install plugin from ZIP**, then pick `AnyAspectRatio-2.1.0.zip`.
